# Supermarket E-Commerce Platform

A full-featured supermarket e-commerce platform developed with **Next.js 15**, **TypeScript**, and **Tailwind CSS**. The project focuses on performance, scalability, and maintainability while providing a modern shopping experience across all devices.

## Highlights

- Modern & Responsive UI
- Product Catalog & Categories
- Product Search
- Shopping Cart
- Customer Profile
- Admin Dashboard
- Product Management
- SEO Optimized
- Database Ready (Supabase)
- Clean & Scalable Architecture

## Technology Stack

- Next.js 15 (App Router)
- React
- TypeScript
- Tailwind CSS
- Supabase
- PNPM

## Current Features

- Responsive Homepage
- Category & Product Pages
- Product Details
- Search System
- Shopping Cart
- Authentication UI
- Admin Product Management
- Reusable Component Architecture
